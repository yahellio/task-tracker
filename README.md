# Трекер задач

Веб-приложение со списком задач, серверным рендерингом разметки и передачей данных через HTML-формы.
Клиентский JavaScript не используется: каждое действие — это отправка формы (`GET`/`POST`) и ответ сервера готовой разметкой.

## Возможности

- Список задач со статусами: «К выполнению», «В работе», «Выполнена».
- Фильтрация по статусу, включая отдельный фильтр «Просрочены», поиск по названию и описанию, сортировка.
- Ожидаемая дата завершения и подсветка просроченных задач.
- Прикрепление нескольких файлов к задаче, их скачивание и удаление.
- Создание, редактирование, быстрая смена статуса и удаление задач.

## Стек

Node.js 20+ (ESM), Express, EJS, Multer. Данные задач хранятся в JSON-файле, файлы вложений — в каталоге на диске.

## Запуск

```bash
npm install
npm start
```

Приложение доступно на `http://127.0.0.1:3000`. Переменные окружения: `PORT`, `HOST`, `DATA_DIR`, `MAX_FILE_SIZE`, `MAX_FILES`.

## Архитектура

```
src/
  domain/          сущности, объекты-значения, порты, ошибки предметной области
  application/     сценарии использования и DTO форм/фильтров
  infrastructure/  реализации портов: JSON-хранилище, файловое хранилище, генератор идентификаторов
  web/             HTTP-слой: маршруты, контроллер, middleware, презентеры, шаблоны EJS
  container.js     composition root: сборка графа зависимостей
  main.js          точка входа
```

| Слой | Ответственность |
| --- | --- |
| `domain` | `Task` с инвариантами и поведением, объекты-значения `DueDate`, `Attachment`, перечисление `TaskStatus`, порты `TaskRepository`, `FileStorage`, `IdGenerator` в `ports.js` |
| `application` | `TaskService` — сценарии над задачами и вложениями; `TaskForm` — разбор и валидация формы; `TaskCriteria` — параметры фильтрации |
| `infrastructure` | `JsonFileStore` (атомарная запись, последовательная очередь операций), `JsonTaskRepository`, `LocalFileStorage`, `UuidIdGenerator` |
| `web` | `createApp`, `routes.js`, `TaskController`, middleware загрузок и ошибок, презентеры и шаблоны |

Разметка собрана из переиспользуемых частей: `partials/head.ejs` и `partials/foot.ejs` задают каркас страницы, `partials/sidebar.ejs` — панель фильтров, `partials/task-card.ejs` — карточку задачи в списке, `partials/task-form.ejs` — общую форму создания и редактирования.

Стили разделены по зонам ответственности: `public/css/base.css` (токены и типографика), `public/css/layout.css` (шапка и сетка «панель фильтров + контент»), `public/css/components/*.css` (кнопки, поля, фильтры, задачи, вложения). Именование классов — BEM.

## Маршруты

| Метод | Путь | Назначение |
| --- | --- | --- |
| `GET` | `/tasks` | Список с фильтрами `status`, `search`, `sort` |
| `GET` | `/tasks/new` | Форма создания |
| `POST` | `/tasks` | Создание задачи с вложениями |
| `GET` | `/tasks/:id` | Карточка задачи |
| `GET` | `/tasks/:id/edit` | Форма редактирования |
| `POST` | `/tasks/:id` | Сохранение изменений |
| `POST` | `/tasks/:id/status` | Быстрая смена статуса |
| `POST` | `/tasks/:id/delete` | Удаление задачи вместе с файлами |
| `POST` | `/tasks/:id/attachments` | Загрузка вложений |
| `GET` | `/tasks/:id/attachments/:attachmentId` | Скачивание вложения |
| `POST` | `/tasks/:id/attachments/:attachmentId/delete` | Удаление вложения |

## Хранение данных

`data/tasks.json` — состояние задач, `data/uploads/` — файлы вложений. Каталог создаётся при старте и исключён из репозитория.
